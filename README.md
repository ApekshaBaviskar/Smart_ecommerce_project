# Smart E-Commerce Project

## Project Description
This project uses Machine Learning to predict customer annual spending
based on customer-related features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Machine Learning Model
- Random Forest Regression

## Notebook
The complete ML implementation is available in:
Smart_Ecommerce_ML_Colab_Cell_by_Cell.ipynb

## How to Run
Open the notebook in Google Colab and run the cells sequentially.
